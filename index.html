One GenAI Product a Week

I've been playing around with GenAI systems for almost half a decade now. In that time, I've built more than my fair share of tech demos using the ever evolving technology. However, my demos never explored the full product/feature lifecycle with GenAI. This project is my attempt to do just that.

For the next 6 weeks, I'm going to build one product prototype a week using a different combination of GenAI systems. The goal of these prototypes is to better explore the capabilities of AI in the open. Where can it most effectively be deployed today? Where are the rough edges? Where can you cut yourself?

For this project, I'll be looking at GenAI systems that are available to the public including LLMs, LVms, and Image Generation systems. Here's a short list of GenAI systems that I'm thinking about incorporating:

  • GPT-4
  • GPT-4 Vision
  • Mistral
  • Llama
  • DALL-E
  • Stability AI

Each week, I'll post a short prototype specification on Monday. I'll then spend the week building the prototype. On Fridays, I'll share a link to the prototype and a writeup on the result of the build process. I've never built in the open before, at least not quite like this. So the process will be a bit of a learning experience for me as well. My hope is this is a useful exercise for myself and a few of you out there.

Most of you got here via a social media post. If you have an idea for a prototype, toss a comment on the social media post, and I'll see if it fits into my format and schedule.

Caveats

Due to the rapid iterative nature of this project, there are a few caveats that I want to call out.

  • These prototypes are scoped down to be achievable in a week.
  • I'm not a designer. These builds are going to prioritize functionality over aesthetics.
  • I'm using a webapp that I previously built to jumpstart all these projects. I'll share the details of that in a future post.
  • Each of the prototypes will require some form of API key to cover the cost of the GenAI system. I DO NOT log those API keys. After the request to the GenAI system is complete, the API key no longer exists in my backend system. The key is stored in the frontend React application for as long as your browser window is open.
